# Invoice Builder

A React-based invoice builder application with real-time calculations and data
persistence.

## Features

- Add, edit, and remove invoice line items
- Real-time calculations (subtotal, tax, discount, total)
- Customizable tax and discount rates
- Currency formatting
- Data persistence with localStorage
- Input validation
- Clean UI with Tailwind CSS

## Requirements

- Node.js 18.0.0 or higher
- npm 8.0.0 or higher

## Setup and Run

1. Navigate to project directory:

```bash
cd invoice-builder
```

2. Install dependencies:

```bash
npm install
```

3. Start development server:

```bash
npm run dev
```

4. Open browser and go to:

```
http://localhost:5173
```

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build

## Technology Stack

- React 19.1.1
- Vite 7.1.2
- Tailwind CSS 4.1.12
